What is the Percentage Calculator?

Work out a percentage of a number, find what percent one number is of another, calculate percentage change, or find an original value.

How to use it

  1. Choose the question that matches your problem.
  2. Type the two numbers.
  3. Press Calculate. Use Clear to try new numbers.

Formula

X% of Y = X ÷ 100 × Y. Percentage change = (New − Old) ÷ |Old| × 100. Original value = Value × 100 ÷ Percent.

Example

15% of 200 = 15 ÷ 100 × 200 = 30. Going from 80 to 100 is a 25% increase.

Important notes

Percentage change uses the absolute value of the old value as its base, so a move from −50 to −25 counts as an increase. Results are rounded to six decimal places.

Frequently asked questions

How do I calculate a percentage increase?

Subtract the old value from the new value, divide by the old value and multiply by 100.

What if the old value is zero?

Percentage change is undefined when the old value is zero, so the tool asks for a different value.
